Early Prediction of Preeclampsia Using Multi-Source Maternal Health Data

Built a machine learning framework to predict preeclampsia risk early across three independent clinical datasets. Trained and compared eight classifiers — including Random Forest, XGBoost, and Gradient Boosting — under deliberately introduced adversarial conditions: class imbalance (SMOTE), label noise, and feature distribution drift. Applied hyperparameter tuning, feature selection, and soft-voting ensemble construction as model improvements. Random Forest achieved the best overall performance with 84.7% test accuracy and AUC of 0.951, with key predictors identified as blood sugar, systolic blood pressure, and hemoglobin.

Python scikit-learn XGBoost SMOTE Pandas Matplotlib Jupyter Notebook

Resilient AI Pipeline for Heart Disease Prediction under Adversarial Big Data Conditions

Built a scalable big data analytics pipeline for heart disease prediction using Apache Spark (PySpark). Simulated a real-world multi-hospital healthcare environment where patient data is distributed across nodes and evaluated under adversarial conditions including missing values, noise injection, label flipping, and data inconsistency. Integrated Kafka streaming for real-time data ingestion and applied federated learning to train models across hospital partitions without centralising sensitive patient data. The pipeline achieved ~78% accuracy on clean data and maintained ~76% under adversarial stress.

Python Apache Spark PySpark Kafka Federated Learning Spark MLlib Pandas NumPy
